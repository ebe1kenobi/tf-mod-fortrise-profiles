Images livrees avec le mod
==========================

Les .png places dans ce dossier sont distribues avec Profiles et apparaissent
dans le vivier de l'ecran IMAGES, marques "MOD".

Pour ajouter les votres sans toucher au mod, deposez-les plutot dans
Saves/Ebe1.Profiles/images/ : meme vivier, et a nom de fichier identique ce
sont eux qui l'emportent.

Six emplacements, un fichier chacun :

  ARCHER      portrait de l'ecran de selection, tenue normale   60x120
  ARCHER_ALT  idem, tenue alternative                           60x120
  WIN         portrait de victoire, ecran de resultats          50x50
  WIN_ALT     idem, tenue alternative                           50x50
  LOSE        portrait de defaite                               50x50
  LOSE_ALT    idem, tenue alternative                           50x50

Les tailles indiquees sont celles du jeu. Une image d'une autre taille est
acceptee et reduite pour tenir dans l'apercu, mais en jeu elle sera dessinee
telle quelle, centree - le cadre du jeu, lui, garde ses dimensions.

Choisir une image en copie le fichier sous
Saves/Ebe1.Profiles/profiles/<PROFIL>/images/<EMPLACEMENT>.png.
