WAV livres avec le mod
======================

Les fichiers .wav places dans ce dossier sont distribues avec Profiles et
apparaissent dans le vivier de l'ecran SOUNDS, marques "MOD".

Leur nom est affiche en majuscules : la police du jeu ne dessine pas
lisiblement les minuscules.

Ils sont en lecture seule : affecter un son a un profil en copie le fichier
sous Saves/Profiles/profiles/<PROFIL>/<EVENEMENT>/.

Pour ajouter des sons sans toucher au mod, deposez-les plutot dans
Saves/Profiles/wav/ : ils apparaissent dans le meme vivier, et a nom de
fichier identique ce sont eux qui l'emportent sur ceux d'ici.

Ce README est ignore : seule l'extension .wav est lue.
